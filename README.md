# 💼 Application de Gestion de Paie

Projet réalisé dans le cadre de la Licence en Ingénierie du Logiciel et des Données à l’Université Internationale Privée d’Excellence (UIE), Bamako.

## 👩🏾‍💻 À propos du projet

Cette application web permet de gérer les agents commerciaux et de générer automatiquement leurs fiches de paie.

Le projet a été mené en équipe de 7 personnes.  
J’ai contribué à la **phase d’analyse** (cahier des charges, modélisation UML) et j’ai été responsable de :

- 🧱 La **conception et le développement complet du backend** (Node.js, Express, MySQL)
- 🔗 L’**intégration entre le backend et le frontend** via JavaScript (gestion des appels API, affichage dynamique, communication client-serveur)

## 🛠️ Technologies utilisées

- **Backend :** Node.js, Express.js
- **Base de données :** MySQL 
- **Frontend :** HTML, CSS (Tailwind), JavaScript (intégration uniquement)
- **Outils :** Postman, GitHub, Trello

## 📌 Fonctionnalités principales

- Authentification avec gestion des rôles (admin, agent)
- Gestion des agents et de leurs performances commerciales
- Calcul automatique des fiches de paie (salaire de base, primes, net à payer)
- Export des fiches de paie en PDF
- Journalisation des actions (historique)
